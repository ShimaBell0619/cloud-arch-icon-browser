Clipboard tests

Three separate ClipboardItem objects, each containing PNG.

A2 · HTML multi-image

One HTML clipboard item containing three embedded PNG images.

C1 · SVG + PNG fallback

One clipboard item exposing SVG first and PNG as a fallback representation.

Direct drag tests

Drag each tile directly into desktop PowerPoint. The first two use standard File/DataTransfer representations. The third is explicitly Chromium-specific exploratory behavior and must not become a production dependency unless the spike proves it reliable.
