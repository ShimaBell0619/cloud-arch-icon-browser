## Feature acceptance coverage

The `v0.2.0` release candidate includes and verifies the following product contracts:

- deterministic search ranking across display name, original filename, and category path,
- explicit removable category filter state,
- keyboard-operable autocomplete,
- persisted Favorites, recently opened icons, and recent searches without persisting ZIP/SVG contents,
- persisted Grid/Compact view and System/Light/Dark theme preferences,
- responsive desktop sidebar and narrow/mobile navigation,
- centered details Dialog with real package metadata only,
- original-byte SVG download with original filename,
- transient transparent 512×512 PNG clipboard copy,
- actionable clipboard permission/API failure feedback.

## Package-content verification

`npm run verify:package` is a mandatory release gate. The package validator uses an explicit top-level allowlist and rejects development/test directories plus ZIP/SVG assets and filenames that resemble the official Microsoft icon package.

No Microsoft ZIP/SVG assets, localStorage state snapshots, or project-owned E2E fixtures are intended to be present in the published package.

## Manual Windows Office verification

This is the only release-blocking verification that cannot be meaningfully completed by CI.

Use the release-polish PR Pages Preview on a Windows machine so the exact release-candidate UI is tested before merge:

1. Open the PR Pages Preview in current Microsoft Edge or Google Chrome on Windows.
2. Select the maintainer-downloaded official `Azure_Public_Service_Icons_V24.zip`.
3. Open any representative icon and choose **Copy image**.
4. Paste into a blank PowerPoint slide.
5. Confirm the icon appears, the background is transparent, and the icon is not visibly stretched or cropped.
6. Repeat **Copy image** and paste into an Excel worksheet.
7. Confirm the same transparency and geometry behavior.
